神经多样性个体自理与启动能力简表（30项）  
Neurodivergent Self-care & Activation Checklist (30-item)

作者：Admin

定位：赋权型（Empowering）的自我探索工具，面向ND（Neurodivergent）个体（含但不限于ASD、ADHD、学习障碍等）。  
用途：识别优势与挑战、形成支持与便利需求画像；非诊断工具。  
作答维度：按“困难程度”评分。  
评估周期：请回忆您在过去两周的通常情况。  
作答方式：请根据每项描述在您身上的“困难程度”进行评分。  

网页版自动计分工具：[点击进入](https://neuroxyz.cn/tests/nsac30.html)

---

## 一、工具目标（What it’s for）

1. 看见“隐形的障碍”  
    传统自理评估多看“是否完成”。NSAC-30强调完成过程中的内在困难：执行功能障碍、感官处理差异、内感受失调如何具体阻滞洗澡、倒垃圾、备餐等日常任务——帮助使用者识别并命名自己的真实卡点。
2. 从“能力标签”到“需求画像”  
    工具不做“能力高低”评判，而是绘制一幅多维度的个人功能性需求画像（建议以雷达图呈现），回答“我在哪些方面需要什么样的支持？”，推动从缺陷导向转向支持导向。
3. 成为沟通与求助的桥梁  
    提供一套结构化语言。例如“我的主要困难在 C（执行功能） 与 D（感官），尤其是任务启动。”——比“我很拖延/很懒”更可操作，便于与家人、同伴、咨询师、医生对齐认知与计划。
4. 优势识别与策略起点  
    锚定困难最集中的维度，针对性设计补偿策略与环境改造，帮助从自责转向主动解决；强调许多困难源自神经差异而非品格问题。

## 二、理论来源与框架
    
把临床/康复的既有框架翻译为第一人称/主观体验取向的自评语言。
    

| 理论来源 | 核心概念 | 在 NSAC-30 的体现 |
| --- | --- | --- |
| 职业治疗与康复医学（OT & Rehab） | ADL / IADL：基础性日常活动与工具性日常活动 | A、B、E、F 四个分量表的结构依据 ADL/IADL 经典分类，覆盖从个人卫生到社区参与的完整生活链条，保证系统性与完整性。 |
| 神经心理学（Neuropsychology） | 执行功能（EF）：计划、组织、启动、抑制、切换、工作记忆等 | C 分量表（执行功能与启动）是核心创新：把抽象 EF 映射为可感知的行为描述（如“启动第一步”“被打断难以回到原任务”），揭示“知道但做不到”的根因。 |

## 三、整合逻辑（Bio-Psycho-Social）

- What（做什么）：来自OT的ADL/IADL结构；
- How（如何做）：来自神经心理学的EF视角；
- Howitfeels（感受如何）：来自感官处理/内感受理论；
- Why（为何困难）：来自残障社会模式与ND肯定范式——强调人-环境适配与支持系统。

**评分标准：**

0=没有困难：能轻松、自主地完成，几乎不消耗心力。 
1=偶尔困难：大部分时候可以，但偶尔会卡住或需要额外努力。  
2=有时困难：大约一半时候能做到，但需要相当大的心力或计划。  
3=经常困难：大多数时候都感到吃力，常常无法完成或需要他人提醒/协助。  
4=几乎总是困难/做不到：几乎无法独立完成，或完成过程极度痛苦。  
（如果某项完全不适用于您的生活，请留空）

## 四、量表内容（The Checklist）

### A.基础自我照护(ADL)

1. 洗浴卫生：能够在你计划或感觉需要时开始并完成洗澡/洗头，而不是拖延数小时甚至数日。

2. 口腔护理：能够每天至少刷牙一次并完成基本的口腔护理。

3. 衣物与整洁：能够根据卫生需要（如出汗后）或至少每天更换内外衣物，保持基本的个人清整。

4. 规律进食：能够每天吃到至少两顿正餐，不会因为忘记、感觉不到饿或觉得准备麻烦而频繁跳过。

5. 作息与精力：能在计划的时间（误差±1小时内）上床，且第二天不会因困倦而严重影响必须完成的要事（如上班、上学）。

### B.家务与居家维护(IADL-Home)

1. 衣物管理：脏衣物能在洗衣篮装满前或至少每周清洗一次，不会因为堆积而导致没有干净衣服穿。

2. 厨房清洁：使用过的餐具和厨房台面能在当天清理，不会因为感官不适（如讨厌的触感、气味）而长时间搁置。

3. 垃圾处理：家里的垃圾能在装满或产生异味前打包并扔掉。

4. 物品秩序：常用必需品（如钥匙、钱包、手机）有相对固定的放置点，出门前能在几分钟内找到它们。

5. 简易备餐：能够独立完成简单的饮食准备（如打开包装、微波炉加热、冲泡饮品）并最终吃/喝下去。

### C.执行功能与启动(EF-Activation)

1. 任务启动：当决定要做某件事后（如写邮件、做家务），能在15分钟内开始第一个相关动作，而不是陷入刷手机、发呆等无关活动中。

2. 任务切换：当正在做的事情被短暂打断后（如接个电话），能在打断结束后重新回到原来的任务上，而不是忘记或转去做别的事。

3. 流程规划：能有计划地完成包含多个步骤的事务（例如：洗澡前会先准备好衣物和毛巾），不会因遗漏步骤而反复折腾。

4. 期限管理：对于有截止日期的重要任务（如付账单、交作业），能提前开始处理，而不是总是拖到最后一刻才匆忙应对。

5. 外出准备：外出前的准备流程（如检查是否带齐钥匙、手机、交通卡、所需药品等）能稳定地完成，很少遗漏。

### D.感官与内感受(Sensory-Interoception)

1. 身体信号觉察：能觉察饥饿、口渴、疲劳、内急等身体信号，并据此采取行动（如吃饭、喝水、休息、去洗手间）。

2. 日常感官耐受：能耐受日常必要的感官刺激（如洗澡的水流、牙膏的味道），不至于因此而完全回避这些活动。

3. 公共环境适应：在必要的公共场合（如超市、医院），不会因为噪音、灯光或气味等感官超载而无法完成任务或提前逃离。

4. 感官偏好管理：感官不适（如衣物标签、特定食物质地）不会长期、严重地阻碍你参与关键的日常活动（如穿衣、吃饭）。

5. 不适信号识别：当身体出现明确的不适（如疼痛、头晕、发烧）时，能识别出这是“需要处理”的信号，并采取相应措施（如休息、吃药、考虑就医）。

### E.医疗与行政(Health-Admin)

1. 预约与就医：能独立完成预约（如线上、电话挂号），并在预约当天按时前往、完成流程。

2. 用药管理：能按照医嘱或说明规律服药，并有策略（如使用药盒、设闹钟）来减少忘记的次数。

3. 表单处理：能独立阅读并填写常见的线上或纸质表格（如挂号单、快递单），不会因为觉得流程复杂而放弃。

4. 窗口业务：需要与工作人员当面沟通才能办理的事务（如在银行、社区窗口），能够完成，即使这会带来社交焦虑。

5. 寻求帮助：当遇到困难无法自行解决时，能在24小时内向他人（朋友、家人、官方客服）求助，而不是无限期搁置。

### F.安全与社会独立(Safety-Community)

1. 厨房安全：能安全地使用基本的厨房设备（如微波炉、电水壶、燃气灶），并在使用后确认其已关闭。

2. 购物支付：能独立在商店或线上完成购物支付，不会因为社交压力或选择过多而中途放弃。

3. 交通出行：能独立使用至少一种公共交通工具或网约车，到达一个熟悉的目的地。

4. 应对变化：面对计划的微小变动（如预约时间推迟半小时、常去的店关门），能调整计划，而不是完全不知所措或情绪崩溃。

5. 功能性沟通：在必要时，能通过电话或当面与陌生人进行简短的功能性对话（如问路、咨询药剂师、与快递员沟通）。

## 五、如何解读你的结果

请带着善意和好奇心看待你的分数。  
这组数字不是对你的评判，而是一张探索你个人世界的独特地图。它标示出了哪些地方是平坦易行的大道，哪些地方是需要消耗更多能量去攀登的山丘，以及哪些地方可能存在需要绕行或搭建桥梁的悬崖。  
我们的目标是读懂这张地图，从而更好地规划你的旅程。

### 第一步：计算你的分数

分量表总分：分别计算每个分量表（A至F）下5道题目的得分总和。每个分量表的满分为20分。

分量表均分：将每个分量表的总分除以5，得到该维度的平均困难程度。

总均分：将所有作答题目的总得分，除以你作答的总题目数量（通常是30），得到你近两周的总体功能负担水平。

### 第二步：绘制你的“个人功能需求画像”

我们强烈建议你使用一个六边形雷达图，将A到F六个分量表的均分分别标注在六个顶点上。连接这些点，你会得到一个独特的形状。这个形状就是你的“个人功能需求画像”，它比单纯的数字更能直观地展示你的优势与挑战。

### 第三步：深度解读你的画像——三步分析法

#### A.识别你的优先支持领域

指标：任一分量表均分≥2.5(即总分≥13分)

这不仅仅是“有点难”，而是你生活中持续消耗大量心力（“勺子”）的领域。这些“高地”是你最需要引入外部支持（如工具、他人协助）或内部策略（如简化流程、降低标准）的地方。

深入思考：这个领域的高分，其根源是什么？请交叉参考你的其他分数：

例如如果B（家务）分数很高，是因为C（执行功能）差，导致你难以启动和规划家务？还是因为D（感官）分数高，让你无法忍受清洁剂的味道或垃圾的触感？找到根源，才能制定出最有效的策略。

#### B.关注你的“悬崖”——急性卡点任务

指标：任何一道题目的得分=4(“几乎总是困难/做不到”)

这些题目代表的不是普遍的困难，而是你生活中的“一道坎”或“一堵墙”。它们是导致生活流程中断、引发强烈挫败感甚至情绪崩溃的急性压力源。

行动导向：这些“悬崖”是寻求精准、微小、具体改变的最佳切入点。不要试图“克服”它，而是思考如何“绕过”它：

分解任务：将任务分解到你愿意做的、最小的第一步（例如“扔垃圾”的第一步是“把新垃圾袋套在垃圾桶边上”）。

寻求替代：是否可以用其他方式完成？（例如如果打电话预约让你崩溃，是否可以选择线上预约？）

请求帮助：是否可以把这一个特定的、让你卡住的步骤外包给家人或朋友？

#### C.欣赏你的现有优势领域

指标：得分较低的分量表（例如均分<1.5）

这些是你的功能优势区，或是你已经无意识地建立起有效应对策略的领域。它们是你信心的来源和成功的案例库。

发掘智慧：花点时间复盘：在这些领域，你做对了什么？你是否建立了一些常规流程（Routine）？你是否在使用某些能帮助你的工具？你是否为自己创造了有利的环境？尝试将这些成功的底层逻辑，“迁移”到你的“高地”领域去。

### 第四步：理解全局图景——你的总体功能状态

指标：总均分≥2.0

这通常表明，你的日常生活正处在一个高消耗、低能量的“生存模式”（SurvivalMode）下。你可能感到持续的疲惫，觉得仅仅是“完成一天”就需要耗尽全力。

这是一个提醒：这不是一个需要恐慌的信号，而是一个邀请你全面审视生活、优先考虑自我关怀（Self-care）的提醒。它表明，零散的技巧可能不足够，你可能需要系统性地引入支持，例如：减少不必要的承诺、寻求专业的咨询或辅导、与家人朋友坦诚沟通你的需求等。

最后请记住：这份量表的结果是一个“快照”，而不是“终身判决”。你的分数会随着你的状态、压力水平、所处环境和获得的支持而动态变化。使用这个工具的真正目的，不是为了得到一个完美的分数，而是为了开启一段更有自我意识的旅程。

**计分与解释（简易版）**

计算方式：分别计算每个分量表（A-F）的总分（0–20分）和总分（0–120分）。

**核心指标：**

分量表均分=分量表总分÷5  
总均分=总分÷作答题目数量

**建议阈值（经验性，非诊断）：**

任一分量表均分≥2.5：表明该领域存在显著的功能负担，建议作为优先关注和寻求支持的领域。  
总均分≥2.0：表明总体日常功能受到明显影响，适合制定一个全面的、阶段性的支持计划。  
任何得分为“4”的题目：代表一个急性的“卡点”，可以优先思考如何为这个具体任务设计微流程、寻求替代方案或请求他人协助。

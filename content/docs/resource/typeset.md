## 公众号排版

微信公众号文章一键排版，脑脑靛青配色，支持 Markdown 语法，实时预览，一键复制到公众号编辑器。

**功能特色**：

- **AI 智能排版**：支持 DeepSeek / OpenAI / Anthropic / 智谱 / 通义千问 / Kimi 等 API，一键自动添加标题、加粗、高亮、引言、列表等排版标记
- **自定义面板**：6 种大标题样式、6 种章节标题样式、6 种小节样式、5 种色板 + 自定义配色、引用/文本框/引言/分割线/表格各有多种样式可选、字号/行距可调、首行缩进开关
- 自动生成文章目录、章节标题自动编号
- 装饰引号引用、高亮标记、重点段落文本框、图片分割线、AI 引言
- 无障碍阅读时长估算、文末署名区
- 一键复制 HTML（含图片）到微信公众号编辑器、导出 PNG
- 支持 MD / DOCX / PDF 文件导入
- **快捷键**：`Ctrl+Enter` 一键复制，`Ctrl+B` 加粗，`Ctrl+Z`/`Ctrl+Y` 撤销/重做

## 小红书排版

小红书图文自动排版，脑脑空间定制 3:4 竖版底图，仓耳今楷字体渲染，自动分页，多页打包下载。

**功能特色**：

- **6 色底图**：专业访谈 / 科普 / 翻译 / 生活访谈 / 绿色 / 待定，各有封面+内页
- **仓耳今楷字体**：Canvas 渲染，保持小红书图文一致的排版风格
- **封面自动生成**：标题居中、副标题、作者、排版人
- **内页自动分页**：小标题置顶，同段文字不跨页，超长段落从句子结尾断页
- **字色可调**：适配不同底图的深浅
- **多页打包下载**：导出全部页面为 ZIP 压缩包（PNG）

**语法格式**：

```
# 标题
## 副标题（可选）
作者：XXX
排版：XXX
---
### 内页小标题
段落文字...
```
